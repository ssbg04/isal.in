# UI & UX Engineering Skill

Use this skill when developing or reviewing user-facing components, layouts, color themes, or design tokens in the Isalin application.

## Core Directives
1. Reference the comprehensive engineering guide: `skills/ui-ux-engineering.md`.
2. Follow Tailwind CSS 4 conventions, using semantic color tokens and border radii (`rounded-xl` for controls, `rounded-2xl` for cards).
3. Test layouts across mobile (375px), tablet (768px), and desktop (1280px+). Ensure no horizontal clipping.
4. Verify dark and light mode contrast using WCAG 2.2 AA guidelines.
5. Provide clear, non-blocking visual feedback for processing, success, and error states.
